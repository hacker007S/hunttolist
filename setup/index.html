HuntToListSheet setup · ~10 minutes

Your research sheet, in six small steps

HuntToList files everything into a Google Sheet you own — there is no HuntToList server. One script, pasted once, turns a blank sheet into the whole pipeline.

1Create a blank sheet

Go to sheets.new and name it, e.g. HuntToList Pipeline. Don't create any tabs — the script builds them all.

2Paste the script

  1. In the sheet: Extensions → Apps Script.
  2. Delete everything in the editor, then paste the script:

For appsscript.json: Project Settings ⚙ → tick “Show appsscript.json”, open it, paste over. It sets the London timezone and the exact permissions. Save with ⌘S / Ctrl+S.

3First run

  1. Function picker → formatSheets → Run.
  2. Google asks to authorise: your account → Advanced → Go to … (unsafe) → Allow. It's your own script in your own account.
  3. Wait ~1 minute for “Execution completed”. Every tab now exists.

4Deploy as a web app

  1. Deploy → New deployment → ⚙ Select type → Web app.
  2. Execute as Me · Who has access Anyone.
  3. Deploy, then copy the Web app URL (…/exec).

The URL is a long secret. For a second lock, set api_token on the sheet's Settings tab and the same value in the extension's Pipeline token.

5Connect the extension

Extension icon → ⚙ Settings → paste the URL into Pipeline URL → Test connection. Expect: “Connected — HuntToList pipeline v90”. Save.

6Tune it (optional)

The sheet's Settings tab controls winner-alert emails, your eBay fee model (business or private, category fee %, VAT) — edit a cell and every winner row's profit recomputes live.

Upgrading later: paste the new script over the old → Save → Run ▶ formatSheets → Deploy → Manage deployments → ✏️ → New version.
