HuntGoSheet setup · ~10 minutes

Your research sheet, in seven small steps

HuntGo files everything into a Google Sheet you own — there is no HuntGo server. One script, pasted once, turns a blank sheet into the whole pipeline.

1Create a blank sheet

Go to sheets.new and name it, e.g. HuntGo Pipeline. Don't create any tabs — the script builds them all.

2Paste the script

  1. In the sheet: Extensions → Apps Script.
  2. Delete everything in the editor, then paste the script:

For appsscript.json: Project Settings ⚙ → tick “Show appsscript.json”, open it, paste over. It sets the London timezone and the exact permissions. Save with ⌘S / Ctrl+S.

3First run

  1. Function picker → formatSheets → Run.
  2. Google asks to authorise: your account → Advanced → Go to … (unsafe) → Allow. It's your own script in your own account.
  3. Wait ~1 minute for “Execution completed”. Every tab now exists.

4Deploy as a web app

  1. Still in the Apps Script editor, click the blue Deploy button (top-right) → New deployment.
  2. In the dialog, click the ⚙ gear next to “Select type” and choose Web app.
  3. Fill the three fields:
    · Description — anything, e.g. HuntGo
    · Execute as — Me (your email)
    · Who has access — Anyone ← this one matters
  4. Click Deploy. If Google asks to authorise again: Authorise access → your account → Advanced → Go to … (unsafe) → Allow.
  5. You'll see two URLs. Copy the Web app one — it ends in /exec — with the Copy button under it. Then click Done.

“Anyone” does not expose your sheet: the URL contains a long random secret, and only someone holding the exact URL can reach the script. Step 6 adds a second lock on top.

5Connect the extension

  1. In Chrome, click the HuntGo icon in the toolbar (pin it via the 🧩 puzzle icon if hidden).
  2. Click the ⚙ gear at the top of the popup — the Settings page opens.
  3. Go to the Pipeline section and paste your /exec URL into Pipeline URL.
  4. Click Test connection. Expect: “Connected — HuntGo pipeline v90”.
  5. Click Save settings (bottom-left).

6Add the token lock (recommended)

One secret typed in two places — after this, requests without it are refused even if someone got your URL.

  1. Open your Google Sheet → click the Settings tab at the bottom.
  2. Find the api_token row and type any secret in its value cell, e.g. hunter-2026-kite.
  3. Back in the extension's ⚙ Settings → Pipeline, paste the same secret into Pipeline token.
  4. Test connection again (should still say Connected), then Save settings.

7Tune it (optional)

The sheet's Settings tab controls winner-alert emails, your eBay fee model (business or private, category fee %, VAT) — edit a cell and every winner row's profit recomputes live.

Upgrading later: paste the new script over the old → Save → Run ▶ formatSheets → Deploy → Manage deployments → ✏️ → New version.
